Application

SecureDocs Entreprise — Microservice de stockage et lecture sécurisée des fichiers.

  • Version API : 1.0
  • Interface : Web SPA
  • Langue : Français

Authentification JWT

Connexion par jeton Bearer stocké localement (sfs_token).

  • Algorithme : HMAC-SHA256
  • OAuth2 / SSO : planifié
  • Refresh token : planifié

Chiffrement

Les fichiers sont chiffrés au repos avec AES-256. Clé maître rotatable par l'administrateur.

  • Intégrité : SHA-256
  • Antivirus : scan à l'upload
  • Permissions granulaires par document
